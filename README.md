## 🛠️ How It Works

AutoCua follows a simple loop that mirrors human behavior:

1. **Look.** It captures what is currently on the screen.
2. **Understand.** It works out what the screen is showing and what needs to happen next.
3. **Act.** It moves the mouse, clicks, scrolls, or types.
4. **Check.** It looks again to confirm the action worked, and repeats until the task is done.

Because the loop includes checking the result, AutoCua can recover from small surprises — a pop-up appearing, a page loading slowly, or a button sitting in a slightly different place than expected.
